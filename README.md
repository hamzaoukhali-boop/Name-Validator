# Username Validator

A clean, modern, and interactive JavaScript DOM manipulation project that validates usernames in real-time. This project is beginner-friendly and built purely with HTML, CSS, and Vanilla JavaScript (No Frameworks).

## 🚀 Features

- **Real-time Validation:** Feedback is given instantly as you type using the `keyup` event.
- **Multiple Validation Rules:**
  - Detects empty usernames
  - Enforces minimum length (5 characters)
  - Prevents spaces
  - Prevents numbers
- **Dynamic Error Rendering:** Errors are displayed as a list generated dynamically via JavaScript.
- **Interactive UI:** Features a modern, responsive card layout with smooth hover effects, focus rings, and entrance animations.
- **Accessible Design:** Clean semantic HTML and clear visual cues for success (green) and error (red) states.

## 🛠 Technologies Used

- **HTML5:** Semantic structure and accessibility.
- **CSS3:** Modern styling, flexbox layout, CSS variables, transitions, and keyframe animations.
- **JavaScript (ES6):** DOM selection, event handling, string manipulation, and regex testing.

## 📦 Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/username-validator.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd username-validator
   ```

## 💻 How to Run Locally

Since this is a static frontend project, you don't need a server to run it.

1. Open the project folder.
2. Double-click on `username-validate.html` to open it in your default web browser.
3. Alternatively, if you use VS Code, you can install the **Live Server** extension, right-click the HTML file, and select "Open with Live Server".
